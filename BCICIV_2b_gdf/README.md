# Dataset Folder

Place BCI Competition IV Dataset 2b `.gdf` files here.

Expected examples:

```text
B0101T.gdf
B0102T.gdf
B0103T.gdf
...
B0901T.gdf
B0902T.gdf
B0903T.gdf
```

The raw `.gdf` files are intentionally not included in this repository.

Official source:

- BCI Competition IV homepage: https://www.bbci.de/competition/iv/
- Download area: https://www.bbci.de/competition/iv/download/
- Dataset 2b description: https://www.bbci.de/competition/iv/desc_2b.pdf
